# 多模态 CARLA 导航避障系统

## 项目简介

本项目基于 **CARLA 模拟器** 与 **深度学习技术**，实现了具备多传感器融合能力的智能车辆导航避障系统。系统集成多视角摄像头、障碍物检测模块、交通信号灯识别等功能，通过多模态数据感知环境，结合神经网络与传统控制算法，实现车辆自主行驶与障碍物规避功能。

## 核心功能

### 1. 多模态感知系统
- **多视角摄像头**：前视、后视、左视、右视、鸟瞰图、第三人称视角
- **速度传感器**：实时获取车辆速度数据
- **障碍物检测**：动态检测并规避前方障碍物

### 2. 车辆控制与辅助
- **智能避障算法**：基于改进神经网络控制器与传统控制器双模式
- **车道保持辅助（LKA）**：自动保持车辆在车道内行驶
- **自动倒车入库**：完整的倒车动作序列（右打死→回正→左打死→微调）
- **双模式控制**：支持神经网络模式与传统控制模式切换

### 3. 环境感知与响应
- **交通信号灯识别**：自动检测红绿灯状态，红灯停车等待，绿灯自动起步
- **交通标志识别（TSR）**：识别限速标志等交通标志
- **天气系统**：支持晴天、雨天、雾天三种天气模式
- **昼夜切换**：支持白天/黑夜模式切换

### 4. 地图与场景管理
- **动态地图切换**：自动检测服务器可用地图，支持无缝切换
- **车型切换**：支持多种车型选择

### 5. 可视化功能
- **多视角显示**：支持2x3网格布局和单一视角模式
- **实时信息叠加**：车速、控制状态、障碍物信息等
- **自动雨刷模拟**：雨天自动工作，根据雨量调整频率

## 快速启动

### 步骤 1：启动 CARLA 模拟器
```bash
CarlaUE4.exe -windowed -ResX=800 -ResY=600
```

### 步骤 2：运行导航避障系统
```bash
cd src/carla_multimodal_navigator
conda activate carla_nav
python main.py
```

## 操作说明

### 基础控制
| 按键 | 功能描述 |
|------|---------|
| `W` | 手动加速 |
| `S` | 手动减速 |
| `A` | 左转向 |
| `D` | 右转向 |
| `Q` | 退出系统 |
| `R` | 重置车辆位置 |

### 视角控制
| 按键 | 功能描述 |
|------|---------|
| `1-6` | 切换不同视角 |
| `SPACE` | 切换单/多视角模式 |

### 功能开关
| 按键 | 功能描述 |
|------|---------|
| `P` | 自动倒车入库 |
| `T` | 交通信号灯识别 |
| `L` | 车道保持辅助 |
| `K` | 交通标志识别 |

### 环境控制
| 按键 | 功能描述 |
|------|---------|
| `7-9` | 切换天气（晴/雨/雾） |
| `0` | 切换昼夜 |
| `,/.` | 切换地图 |
| `M` | 切换车型 |

## 技术亮点

- **多传感器融合**：集成视觉、速度、距离等多种传感器数据
- **深度学习集成**：结合神经网络与传统控制算法
- **模块化设计**：各功能模块独立，易于扩展和维护
- **实时可视化**：提供丰富的实时信息展示
