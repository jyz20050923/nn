# 多模态 CARLA 导航避障系统

基于 CARLA 模拟器与神经网络技术，实现具备多传感器融合能力的智能车辆导航避障系统。

## 核心功能

### 1. 多模态感知系统
- **多视角摄像头**：前视、后视、左视、右视、鸟瞰图、第三人称，支持2x3网格和全屏显示
- **速度传感器**：实时获取速度数据，采样频率10Hz，单位km/h
- **碰撞检测**：检测前方±60°范围内50米内障碍物，计算碰撞风险等级

### 2. 车辆控制与辅助
- **智能避障**：双模式控制器（神经网络+传统控制），支持紧急刹车、减速跟随、转向避让
- **车道保持辅助（LKA）**：基于OpenCV车道线检测，自动调整方向盘保持车道居中
- **自动倒车入库**：完整动作序列（刹车→右打→回正→左打→微调→停车），约10秒完成

### 3. 环境感知与响应
- **交通信号灯识别**：识别红黄绿信号灯，自动调整车速响应
- **交通标志识别（TSR）**：识别限速、停车让行等标志
- **天气系统**：晴天、雨天、雾天三种模式，支持手动切换和自动变化
- **昼夜切换**：按0键切换白天/黑夜，调整光照参数

### 4. 车辆状态监控
- **仪表盘**：实时显示车速、转速、方向盘状态
- **状态监控**：油量、引擎温度、电池电量、胎压实时监控

## 环境配置

- **操作系统**：Windows 10/11 或 Ubuntu 20.04/22.04
- **Python**：3.7+
- **CARLA**：0.9.16+
- **依赖库**：carla, numpy, opencv-python, torch, matplotlib

## 安装指南

```bash
# 创建虚拟环境
conda create -n carla_nav python=3.7
conda activate carla_nav

# 安装依赖
pip install numpy opencv-python matplotlib torch
pip install carla==0.9.16  # 根据CARLA版本调整
```

## 快速启动

### 步骤1：启动 CARLA 模拟器
```bash
CarlaUE4.exe -windowed -ResX=800 -ResY=600  # Windows
```

## 系统架构

```
传感器层 → 核心处理模块 → 可视化层
  ↓            ↓              ↓
摄像头       环境感知        多视角显示
速度传感     决策规划        仪表盘

```

## 故障排除

- **连接失败**：确保CARLA模拟器已启动，端口2000未被占用
- **画面黑屏**：检查CARLA版本与Python API版本是否匹配
- **车辆不动**：检查油门值，尝试按R键重置车辆
