# 多模态 CARLA 导航避障系统

## 项目简介

本项目基于 CARLA 模拟器与神经网络技术，实现了具备多传感器融合能力的智能车辆导航避障系统。系统集成多视角摄像头、障碍物检测模块、交通信号灯识别等功能，通过多模态数据感知环境，结合神经网络与传统控制算法，实现车辆自主行驶与障碍物规避功能。

## 核心功能

### 1. 多模态感知系统
- **多视角摄像头**：前视、后视、左视、右视、鸟瞰图、第三人称视角
- **速度传感器**：实时获取车辆速度数据
- **障碍物检测**：动态检测并规避前方障碍物

### 2. 车辆控制与辅助
- **智能避障算法**：基于改进神经网络控制器与传统控制器双模式，动态检测并规避前方障碍物
- **车道保持辅助（LKA）**：自动保持车辆在车道内行驶
- **自动倒车入库**：完整的倒车动作序列（右打死→回正→左打死→微调），完成后持续刹车保持静止
- **双模式控制**：支持神经网络模式与传统控制模式切换，可根据环境选择最优控制策略

### 3. 环境感知与响应
- **交通信号灯识别**：自动检测前方50米范围内的红绿灯状态，红灯自动停车等待，绿灯自动起步
- **交通标志识别（TSR）**：识别限速标志等交通标志
- **天气系统**：支持晴天、雨天、雾天三种天气模式
- **昼夜切换**：支持白天/黑夜模式切换

### 4. 地图与场景管理
- **动态地图切换**：自动检测服务器可用地图，支持无缝切换，自动跳过不可用地图
- **车型切换**：支持多种车型选择（Tesla Model 3、Toyota Prius、Audi A2等）

### 5. 可视化功能
- **多视角显示**：支持2x3网格布局和单一视角模式
- **实时信息叠加**：车速、控制状态、障碍物信息等关键信息
- **自动雨刷模拟**：雨天自动工作，根据雨量强度调整刮刷频率（关闭/间歇/慢速/快速）

## 环境配置

- 操作系统：Windows 10/11 或 Ubuntu 20.04/22.04
- Python 版本：3.7
- 核心框架：PyTorch
- 模拟器：CARLA 3.16

## 依赖安装

创建虚拟环境：

```bash
conda create -n carla_nav python=3.7
conda activate carla_nav
```

安装 CARLA 模拟器（参考 CARLA 官网）。

安装 Python 依赖包：

```bash
pip install carla numpy opencv-python matplotlib
pip install setuptools==40.2.0
pip install wheel
pip install torch
pip install opencv-python
```

安装 CARLA Python API：

```bash
pip uninstall carla -y
pip install D:/项目名/hutb/PythonAPI/carla/dist/hutb-2.9.16-cp37-cp37m-win_amd64.whl
```

## 核心功能详解

### 1. 自动倒车入库

**功能描述**：实现完整的倒车入库动作序列，模拟真实倒车入库操作。

**动作序列**：
1. **刹车阶段**：车辆减速至停止
2. **右打死倒车**：向右打死方向盘，开始倒车
3. **回正倒车**：回正方向盘，继续倒车
4. **左打死调整**：向左打死方向盘，调整车身位置
5. **微调摆正**：轻微调整，摆正车身
6. **停车完成**：刹车停车，完成入库

**操作方式**：按 `p` 键开启/关闭自动倒车入库

**特点**：
- 完整的状态机控制，实时显示泊车进度（0-100%）
- 完成后持续刹车保持静止，不会自行移动

### 2. 交通信号灯识别

**功能描述**：自动检测前方交通信号灯状态，根据信号灯颜色自动控制车辆。

**检测范围**：前方50米，±45°视角范围内

**控制策略**：
| 信号灯状态 | 距离条件 | 控制行为 |
|-----------|---------|---------|
| 红灯 | < 15 米 | 自动刹车停车 |
| 黄灯 | < 20 米 | 减速准备停车 |
| 绿灯 | 任意 | 正常行驶 |

**操作方式**：按 `t` 键开启/关闭交通信号灯识别

**视觉效果**：
- 右上角显示信号灯图标（红/黄/绿）
- 显示状态文字（STOP/CAUTION/GO）
- 显示与信号灯距离

### 3. 地图切换功能

**功能描述**：支持动态获取服务器可用地图，实现无缝地图切换。

**操作方式**：
- 按 `,` 键切换到上一个地图
- 按 `.` 键切换到下一个地图

**特点**：
- 动态检测服务器可用地图，自动跳过不可用地图
- 切换时自动重新生成车辆和传感器
- 保持原有功能状态

### 4. 自动雨刷模拟

**功能描述**：雨天自动启动雨刷，根据雨量调整刮刷频率。

**雨刷模式**：
| 雨量强度 | 雨刷模式 | 效果 |
|---------|---------|------|
| <10% | OFF | 雨刷停止 |
| 10%-30% | INTERMITTENT | 间歇刮刷 |
| 30%-60% | SLOW | 慢速连续刮刷 |
| >60% | FAST | 快速连续刮刷 |

**操作方式**：按 `8` 键设置雨天，雨刷自动工作

**视觉效果**：
- 前视画面显示雨刷摆动动画
- 右上角显示当前雨刷状态

## 系统架构

1. **环境初始化模块**：连接 CARLA 服务器（默认 localhost:2000），加载 Town01 地图，设置同步模式（固定时间步长 0.1s），配置天气参数（云量30%、无降水、太阳高度角70°）
2. **智能体生成模块**：主车辆为特斯拉 Model3（红色），关闭自动驾驶，由自定义控制算法控制；NPC 车辆随机生成3辆不同类型车辆，开启自动驾驶，分散在50米外起始位置
3. **传感器系统**：前视摄像头（90°视野，分辨率640×480，用于神经网络输入）；第三视角摄像头（110°视野，分辨率640×480，用于可视化监控）；障碍物检测器（实时检测前方±60°范围内50米内障碍物）；多视角摄像头系统（6个视角覆盖360°）
4. **控制系统**：神经网络控制器基于改进的 SimpleDrivingNetwork，融合图像与障碍物信息；传统控制器基于路点跟踪的经典控制算法，稳定性更高；障碍物避障逻辑支持紧急刹车、减速跟随、转向避让多级策略；自动倒车入库状态机控制
5. **可视化与监控**：实时显示多视角画面，可视化障碍物位置与距离，显示车速、控制模式、油门/刹车/转向值，安全区域标记与卡住警告，交通信号灯状态显示，雨刷动画效果
6. **深度神经网络**：网络架构为3层卷积提取图像特征，融合障碍物三维特征，全连接层输出归一化控制指令；容错策略为异常时自动切换传统控制，输出超限触发软限制
